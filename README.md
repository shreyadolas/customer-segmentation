# Customer Segmentation Dashboard

A customer segmentation project using **RFM (Recency, Frequency, Monetary) analysis** to identify different customer groups and support data-driven marketing decisions.

## Project Overview

This project analyzes customer transaction data and segments customers based on their purchasing behavior.

The Streamlit dashboard provides:
- Total customers
- High-value customers
- At-risk customers
- Total revenue
- Customer segment distribution
- City and segment filters

## Customer Segments

The customers are classified into:

- High-Value Customer
- Loyal Customer
- At Risk
- New Customer
- Low-Value Customer

## Technologies Used

- Python
- Pandas
- Streamlit
